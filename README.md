# Currency Rates — курсы валют через open.er-api.com

Курсовой проект VPd02 «Документация и форматы данных»: запрос курсов валют,
кэширование ответа в JSON и мини-CLI с конвертацией суммы.

**Версия 2** — модульная структура по пункту 7: `api_client.py` (HTTP), `storage.py` (I/O),
`cli.py` (интерфейс), `currency.py` (фасад и точка входа). Поведение и критерии приёмки
те же, что в версии 1; версия 1 остаётся в репозитории `Currency_Rates_progect`.

## Что осваиваем

- чтение документации API и работа с JSON-ответом;
- GET-запрос с параметром в пути, проверка статуса и тела ответа;
- кэширование в файл с временем жизни 24 часа;
- человеко-читаемые ошибки вместо стектрейса;
- конвертация суммы через кросс-курс.

## Ключевые поля ответа `latest`

| Поле | Что содержит |
|---|---|
| `base_code` | базовая валюта, к которой посчитаны курсы (`USD`) |
| `time_last_update_utc` | когда курсы обновлены (строка UTC) |
| `time_next_update_utc` | когда будет следующее обновление |
| `rates.RUB` | сколько RUB за 1 базовую единицу |
| `rates.USD` | сколько USD за 1 базовую единицу (для базы USD — `1`) |

Дополнительно: `result` (`success` / `error`), `error-type` (причина ошибки),
`rates` — словарь всех поддерживаемых кодов.

> В тексте задания поля названы `conversion_rates.*`. Актуальный open-эндпоинт
> `open.er-api.com/v6/latest/{base}` отдаёт их в ключе `rates`; `conversion_rates`
> встречается только в старых материалах. Код поддерживает оба варианта.

## Чей это курс: регион, банк, время

- В запросе есть только базовая валюта (`/latest/USD`), **параметра региона или банка нет**.
  Ответ — один общий набор курсов провайдера `exchangerate-api.com`; он не различается
  «для Лондона» и «для Пекина».
- Время обновления — **UTC**, курсы обновляются примерно раз в сутки.
- Это **ориентировочный рыночный курс**, а не курс покупки/продажи конкретного банка
  или обменника: у банков своя наценка и свой курс на каждый день.
- Конвертация считается из этого же набора: `amount * rates[to] / rates[from]`.
  Если база совпадает с исходной валютой, `rates[from] = 1`.
- Нужен курс конкретного банка или региона — нужен его собственный источник; этот API
  для справки и учебных расчётов.

## Запуск

```powershell
git clone https://github.com/IgorL0SEV/Currency_Rates_progect_v2.git
cd Currency_Rates_progect_v2
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python currency.py
```

Меню:

- `1` — показать курсы к текущей базовой валюте (RUB, EUR, GBP);
- `2` — конвертировать сумму (по умолчанию из базовой валюты, 4 знака);
- `3` — сменить базовую валюту сессии;
- `4` — найти валюту: код, начало кода или Enter для всего списка;
- `5` — принудительно обновить данные из API для текущей базы;
- `6` — состояние кэша: возраст, база, время обновления API;
- `0` — выход.

Над меню всегда виден контекст: текущая база и что с кэшем (`актуален`, `устарел`,
`данных нет`). Пункт 1 не спрашивает валюту — считает от текущей базы; сменить её можно
пунктом 3. Коды проверяются до запроса: нужны три латинские буквы (`USD`, `EUR`),
ввод `1` или `US` даёт понятное сообщение, а не HTTP 404.

Кэш — `currency_rate.json`, создаётся при первом запросе. Если файл моложе
24 часов и снят для той же базовой валюты, данные читаются из него.

(`get_currency_rates`, `save_to_file`, `read_from_file`) через реэкспорт.

## Проверка

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты не ходят в сеть: HTTP-ответы и файлы подменяются `unittest.mock`.

## Что проверено вручную

- `python currency.py` в чистом venv: запрос к API, создание `currency_rate.json`;
- повторный запуск: данные берутся из кэша (`источник: кэш`);
- «состаривание» файла: снова запрос к API (`источник: API`);
- неизвестный код валюты: `[ОШИБКА] API отклонил запрос: unsupported-code...`, без стектрейса;
- конвертация USD→RUB и EUR→GBP: одинаковый результат для кэша и свежего ответа;
- пункт 3: смена базы (`EUR`), пункт 1 сразу считает от новой базы;
- пункт 4: точный код, начало кода (`EU` → `EUR`), Enter — весь список; неизвестный ввод — весь список с пояснением;
- пункт 5: принудительный запрос к API перезаписывает кэш;
- пункт 6: возраст кэша, база, время обновления.

## Ограничения

- API отдаёт курсы раз в сутки — внутри дня данные одинаковые.
- Кэш один на все базовые валюты: при смене базы файл перезаписывается.
- Ключ API не нужен; лимиты open-эндпоинта — на усмотрение провайдера.
